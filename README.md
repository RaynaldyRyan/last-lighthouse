**The Last Lighthouse** — you are the lighthouse. Guide the fleet home
through the fog and burn what hunts in it. Aim the beam with the mouse, hold
click to focus it for triple damage, and keep the lamp fed: ships that sail
too long unlit turn away and are lost, and fog creatures chew the tower's
hull. Five nights, a gold shop between each (brighter lens, wider prism,
deeper tank, iron tower, storm turret), five collectible relics, a combo
system — and the Kraken waiting on night 5. All art is drawn in code and all
sound is synthesized with WebAudio; the game runs offline from static files.

## Run it

```sh
npx serve game
# or: python3 -m http.server -d game
# then open http://localhost:8000 in desktop Chrome
```
